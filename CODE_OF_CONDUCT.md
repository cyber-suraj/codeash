# Code of Conduct

## Our commitment

CodeAsh is built for a security-focused hackathon and an open-source community.
Participants, contributors, and maintainers are expected to make participation
harassment-free for everyone, regardless of age, body size, disability,
ethnicity, gender identity and expression, experience level, education,
nationality, personal appearance, race, religion, or sexual identity and
orientation.

This project also follows the **Hacktoberfest Hack Day — NIAT-ADYPU**
organizer's Code of Conduct. If the organizer's rules are stricter, those rules
take precedence.

## Expected behavior

- Be respectful, specific, and constructive in reviews and discussions.
- Critique code and ideas, not people.
- Assume good faith while still requiring evidence for security claims.
- Respect privacy. Do not publish another person's credentials, source code,
  personal data, or private messages.
- Disclose AI assistance and verify generated code before submitting it.
- Report vulnerabilities in CodeAsh privately rather than opening a public
  issue with exploit details.

## Unacceptable behavior

- Harassment, intimidation, discrimination, or hateful conduct.
- Personal attacks, trolling, or sustained disruption.
- Publishing private information without explicit permission.
- Submitting real credentials, customer data, or proprietary source code as
  test fixtures.
- Plagiarism, undisclosed copied work, or misrepresenting AI-assisted work as
  unaided work.
- Retaliation against anyone who reports a concern in good faith.

## Scope

This policy applies in the repository, issues, pull requests, discussions,
demo sessions, event communications, and any space where someone represents
CodeAsh or the event.

## Reporting and enforcement

For a conduct concern, contact the repository maintainer privately through the
contact method on the [maintainer's GitHub profile](https://github.com/cyber-suraj)
or raise it with the event organizers. Do not open a public issue for a
sensitive conduct report.

The maintainer will review reports in good faith, protect the reporter's
privacy where possible, and take proportionate action. Possible actions include
a private warning, removal of content, rejection of a contribution, or a
temporary or permanent ban from project spaces. Appeals can be sent through the
same private channel.
